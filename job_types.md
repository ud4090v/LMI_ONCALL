##The Different job types are as follows (seen in column F of the excel):
•	AFT/MFT (File Transfers)
•	Filewatchers (Monitor Files in the system)
•	Data Services (Run scripts in Data Services)
•	Resource (Limit multiple runs of the same job)
•	SAP Program (Runs a process in SAP)
•	Sleep (Jobs that delay a job stream to ensure full processing is complete)
•	Unix Scripts (Run unix commands)
•	Windows Bat (Run windows commands)
